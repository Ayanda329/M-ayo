MY TUCKSHOP INSTALLABLE WEB APP

This folder contains the files for a Progressive Web App (PWA). Upload all files and folders here to a static HTTPS hosting service. index.html must be at the website root.

Files: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.

Phone-only route using GitHub Pages:
1. Sign in or create a free account at github.com in your phone browser.
2. Create a new public repository named my-tuckshop-app.
3. Choose Add file > Upload files and upload all five files from this ZIP (extract ZIP first using your phone Files app). Commit the upload.
4. In the repository, open Settings > Pages. Under Build and deployment choose Deploy from a branch; choose main and / (root), then Save.
5. Wait for GitHub Pages to publish. The site URL will be https://YOUR-USERNAME.github.io/my-tuckshop-app/ .
6. Open that URL in Chrome while online. Tap ⋮ > Install app (or Add to Home screen). Open it once online, then test airplane mode.

Back up records regularly. Records are stored locally on the device/browser and do not sync between devices. Do not clear browser/site storage.
